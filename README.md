# Sistema Completo de Boletería e Ingreso Institucional

## Descripción
Sistema de gestión de eventos, venta de entradas, control de acceso en puerta y reportes en Excel.

## Requisitos
- Node.js (v16.x o superior)
- npm

## Instalación y Puesta en Marcha
1. Descomprime este archivo `.zip`.
2. Abre una consola/terminal en la carpeta descomprimida.
3. Instala las dependencias necesarias:
   ```bash
   npm install
   ```
4. Inicia el servidor Node.js:
   ```bash
   npm start
   ```
5. Accede a los módulos desde tu navegador web:
   - **Boletería / Cliente:** `http://localhost:3000/`
   - **Dashboard Admin:** `http://localhost:3000/admin.html`
   - **Control de Acceso Puerta:** `http://localhost:3000/puerta.html`
